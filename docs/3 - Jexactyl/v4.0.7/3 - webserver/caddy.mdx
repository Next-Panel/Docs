# Usando Caddy

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';
import { CaddyNoSSL, CaddySSL, CaddyDockerNoSSL, CaddyDockerSSL } from '@site/src/components/Pages/Caddy';

<Tabs>
  <TabItem value="host" label="Maquina Host" default>

Se você instalou o painel diretamente em `/var/www/jexactyl` com **PHP 8.4**, edite `/etc/caddy/Caddyfile` e substitua `<domain>` pelo seu domínio ou IP:

<Tabs groupId="ssl">
  <TabItem value="ssl" label="Com SSL" default>
    <CaddySSL jex={true} phpVersion="8.4" />
  </TabItem>
  <TabItem value="nossl" label="Sem SSL">
    <CaddyNoSSL jex={true} phpVersion="8.4" />
  </TabItem>
</Tabs>

```bash
sudo systemctl reload caddy
```

  </TabItem>
  <TabItem value="docker" label="Docker">

Se você subiu o painel via Docker com `PANEL_PORT=127.0.0.1:8085` e `TRUSTED_PROXIES=*`, adicione ao seu `/etc/caddy/Caddyfile`:

<Tabs groupId="ssl">
  <TabItem value="ssl" label="Com SSL Automático" default>
    <CaddyDockerSSL />
  </TabItem>
  <TabItem value="nossl" label="Sem SSL">
    <CaddyDockerNoSSL />
  </TabItem>
</Tabs>

```bash
sudo systemctl reload caddy
```

  </TabItem>
</Tabs>
