# Usando Nginx

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';
import { NginxNoSSL, NginxSSL, NginxDockerNoSSL, NginxDockerSSL } from '@site/src/components/Pages/Nginx';

<Tabs>
  <TabItem value="host" label="Maquina Host" default>

Se você instalou o painel diretamente em `/var/www/jexactyl` com **PHP 8.4**, remova o site padrão e crie `/etc/nginx/sites-available/panel.conf`:

```bash
sudo rm -f /etc/nginx/sites-available/default /etc/nginx/sites-enabled/default
sudo nano /etc/nginx/sites-available/panel.conf
```

Substitua `<domain>` pelo seu domínio ou IP:

<Tabs groupId="ssl">
  <TabItem value="ssl" label="Com SSL" default>
    <NginxSSL jex={true} phpVersion="8.4" />
  </TabItem>
  <TabItem value="nossl" label="Sem SSL">
    <NginxNoSSL jex={true} phpVersion="8.4" />
  </TabItem>
</Tabs>

```bash
sudo ln -sf /etc/nginx/sites-available/panel.conf /etc/nginx/sites-enabled/panel.conf
sudo nginx -t
sudo systemctl restart nginx
```

  </TabItem>
  <TabItem value="docker" label="Docker">

Se você subiu o painel via Docker com `PANEL_PORT=127.0.0.1:8085` e `TRUSTED_PROXIES=*`, crie `/etc/nginx/sites-available/jexactyl.conf`:

<Tabs groupId="ssl">
  <TabItem value="ssl" label="Com SSL" default>
    <NginxDockerSSL />
  </TabItem>
  <TabItem value="nossl" label="Sem SSL">
    <NginxDockerNoSSL />
  </TabItem>
</Tabs>

```bash
sudo ln -sf /etc/nginx/sites-available/jexactyl.conf /etc/nginx/sites-enabled/jexactyl.conf
sudo nginx -t
sudo systemctl restart nginx
```
